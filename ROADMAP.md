# 🚀 Gitgud Development Roadmap

Gitgud is a B2B2C sports ecosystem. This roadmap follows the "Zero Stubs" principle: functionalities only appear when they are fully operational with backend support.

## 🗺️ Roadmap Overview

### [PHASE 1] Identity & Metrics (CURRENT)
**Focus:** The Athlete Experience.
- [x] Database Schema: Profiles, XP, Levels, Streaks.
- [x] Core Features:
    - User Profile (Identity).
    - Progression System (XP/Levels).
    - Training Metrics (Attendance/Frequency).
- [ ] UI/UX: Mobile-first dashboard for athletes.

### [PHASE 2] B2B Core (The Professional)
**Focus:** Management for Coaches & Schools.
- [ ] Database Schema: Schools, Coaches, Classes, Enrollments.
- [ ] Core Features:
    - School/Coach Profile.
    - Class Creation & Management.
    - Student Enrollment & Attendance Tracking.
- [ ] UI/UX: Tablet-optimized Dashboard for coaches.

### [PHASE 3] Competition (Tournaments)
**Focus:** Engagement through competition.
- [ ] Database Schema: Tournaments, Brackets, Results.
- [ ] Core Features:
    - Tournament Creation.
    - Brackets & Leaderboards.
    - Match Results Reporting.
- [ ] UI/UX: Tournament discovery & viewing.

### [PHASE 4] Asset Economy (Renting & Selling)
**Focus:** Monetization tools for users.
- [ ] Database Schema: Rentals, Marketplace Items.
- [ ] Core Features:
    - Court/Space Renting.
    - Equipment Marketplace (Selling/Buying).
- [ ] UI/UX: Marketplace browsing & Rental booking.

### [PHASE 5] Financial Layer (Payments)
**Focus:** Full automation.
- [ ] Database Schema: Transaction logs, Payment gateway integration.
- [ ] Core Features:
    - Automated Class Payments.
    - Subscription Models.
- [ ] UI/UX: Seamless Checkout.
